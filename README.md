# Daily Mentor Video Downloader

Bulk download videos from Loom with real-time progress tracking.

## Quick Start

1. **Install dependencies:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

2. **Run the app:**
```bash
python3 app.py
```

3. **Open browser:**
```
http://localhost:8888
```

## How to Use

- Select videos or chapters with checkboxes
- Click "Download Selected"
- Videos save to `~/downloads/daily_mentor`
- Change download location in the UI if needed

## Stop Server

Press `Ctrl+C` in the terminal
